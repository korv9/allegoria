# Simulacria data product

Simulacria belongs under `products`, but it has no executable pipeline yet.

Its future source will be versioned model transformations and reconstructions. Those records do
not exist before the Allegoria data foundation and model contracts have been reviewed. Creating
empty Bronze, Silver, and Gold notebooks now would invent schemas and duplicate LAS data without
a real transformation.

No Simulacria Databricks job or Unity Catalog table is therefore created in this phase. Its first
schema will be designed from real generation output, in accordance with the project's data-first
rule.
